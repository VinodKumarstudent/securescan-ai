🛡️ About SecureScan AI & Legal Compliance

SecureScan AI is a defensive web application security testing and compliance auditing platform designed for authorized security practitioners, students, and system owners.

Core Safety & Ethics Controls

  • Strict Ownership Enforcement: No scans can be executed without verified ownership (DNS TXT / HTML meta tag / file upload) or signed written authorization.
  • Active SSRF Protection: Resolves hostnames in real-time and blocks private networks (RFC 1918), loopback, link-local, and cloud metadata endpoints (169.254.169.254) unless explicitly authorized as an educational lab target.
  • Non-Destructive Detection Only: Employs harmless benign probe markers. Never executes Denial-of-Service (DoS), database truncation, data extraction, or persistent modifications.
  • Rate-Limited & Transparent: Restricts request velocity (requests per second) and sends an explicit SecureScanAI/1.0 User-Agent disclosing contact information.
